# Galbot Piano Web UI

这是项目的本地调试页面。它不引入额外 Web 框架，直接使用 Python 标准库启动；机器人控制仍依赖目标机器已安装的 `galbot_sdk`。所有控制都位于一个单页仪表盘中，没有路由跳转或分页；桌面端将控制、选曲和日志排布在同一工作区。

## 启动

在已安装项目依赖和 Galbot SDK 的环境中，从仓库根目录运行：

```bash
python webui/server.py
```

然后访问 <http://127.0.0.1:8080>。如端口被占用，可指定其他端口：

```bash
python webui/server.py --port 8090
```

服务默认只监听 `127.0.0.1`，不会暴露到局域网。

## 提供的调试动作

- **连接 / 断开**：Web UI 直接调用 `GalbotRobot.init()` 和既有的资源释放流程。页面的“已连接”表示 `init()` 已成功返回。
- **双手安全归零**：发送现有曲目脚本所用的安全张开姿态：拇指旋转为 `0`，其他关节为 `1000`。
- **选曲与启动**：可选择《小星星》或《茉莉花》。启动后，Web UI 会释放自己的 SDK 连接，再用独立子进程执行原有演奏脚本，使曲目逻辑保持不变。
- **软停止**：向子进程发送 `Ctrl+C`（Windows）或 `SIGINT`（Linux），让原有脚本走既有的手部复位和资源释放流程。不会使用强制终止。
- **现场日志**：子进程 stdout 会显示在页面中，用于排查 SDK、IK 和指令返回状态。
- **主题切换**：右上角可在白天与暗黑模式间切换；选择会保存到当前浏览器。

## 安全边界

页面中“机器人姿态归零”当前仅实现为**双灵巧手安全张开**，不是机械臂或全身关节的零位动作。全身归零需要先按现场机械臂初始姿态、碰撞空间和 Galbot SDK 的官方接口确认后才能接入，不能在缺少这些信息时猜测调用。

演奏过程中，页面禁用连接、断开、选曲和归零，以避免多个控制指令同时占用机器人。
